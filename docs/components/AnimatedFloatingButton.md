# AnimatedFloatingButton

A customizable animated floating action button (FAB) component with a rotating gradient effect.

## Features

- Smooth entrance animation with slide-in effect
- Continuous rotating gradient background
- Customizable size and position
- Dark mode support
- Press handling capability

## Props

| Prop | Type | Required | Description |
|------|------|----------|-------------|
| onButtonPress | () => void | Yes | Callback function triggered when the button is pressed |
